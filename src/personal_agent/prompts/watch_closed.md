The observed result establishes that nothing further can change within the current accepted watch window. The accepted goal and offer define what can count as final. Say yes only for an explicitly observed final state that leaves no part of that window to monitor. An unchanged result, missing data, a failed check, or an unresolved condition is not final. This decision concerns the current window only. The facts give when this is judged, the window's last check and how many checks are still left in it. While checks are left, say yes only when the result shows a state that cannot change before that last check; a result that may still change before then is not final, however settled it looks now.
