Here with you.

AI 可以更换，你的助手始终延续。

在你自己的电脑上运行的开源个人智能体。更换 AI 时，仍保留关于你的记忆、进行中的工作和你授予的权限。

安装 Still查看真实使用

AI 可以换，助手还是那一个。

干活的是你的 ChatGPT 订阅（经由 Codex）或 Claude 订阅（经由 Claude Code）。聊到一半也能用一条命令切换，Still 接着往下做。

想换就能换

  • Codex
  • Claude Code
  • API 密钥
  • Ollama
  • 工具和连接

一直跟着你

  • 它对你的了解
  • 没做完的事
  • 你交给它的权限
  • 实际执行过的记录

少一点重复解释。

让关于你的记忆、对话和你选择的工具相互连接。

不必多说，它记得。

上周告诉它的事，会在需要的时候派上用场，它也会说明每条记忆的依据。每一次记下都可以撤销。

对话示例

周一

我家猫最近不怎么吃饭，该怎么办？

可以先试试这几个办法……我记下了你养猫。

周四

帮我挑一台 3000 元以内的扫地机器人。

3000 元以内有三款。最能对付猫毛的那款我放在了第一个。

展开真实画面

在你常聊天的地方，用你已经在用的工具。

在这些地方和它聊

  • Telegram
  • Slack
  • 终端
  • Mattermost
  • 浏览器

它能配合使用

  • 你的文件夹
  • Gmail
  • Google 日历
  • Google 云端硬盘
  • 你登录的网站

文件夹默认只读，除非你另有说明。整理 Gmail 需要单独授权，而且 Still 从不发送邮件。

边聊边做，停在你决定的地方。

开始较长的任务前，它会告诉你打算怎么做、由哪个 AI 来做。期间你可以问别的事，也可以中途纠正它。

对话示例

帮我给妈妈挑个 300 元以内的生日礼物。

Codex我会找她每天都用得上的东西，看看评价和送达时间，再挑三样给你看。

日语的“谢谢”怎么说？

ありがとうございます（Arigatō gozaimasu）。礼物还在继续找。

  • 只用你连接的。 只使用你选择的文件夹、账号和工具。
  • 付款等你确认。 加入购物车和付款是两个不同的操作，每一次付款都需要你批准。
  • 密钥不外泄。 密码和令牌不会进入模型提示词、日志或执行记录。

今晚就把 Still 带回家

一台 Mac、Linux 或 Windows（WSL2）电脑，加上你已经在用的 ChatGPT 或 Claude 订阅，就够了。

curl -LsSf https://raw.githubusercontent.com/Jongtae/Still/ebf97d4150be3eb867649a31e79287f05db02886/scripts/install.sh | sh

安装脚本的地址固定在一个版本上，运行前可以先查看脚本内容。在 Apple 芯片的 Mac 上用 Homebrew 的话：brew tap jongtae/still https://github.com/Jongtae/Still、brew install jongtae/still/agentos，再运行 agentos start。Windows 上，在 PowerShell 中运行 wsl --install 并重启，打开 Ubuntu，把上面的命令粘贴进去。

  1. 选择你的 AI

    设置在终端里进行。选择 Codex、Claude Code 或 API 密钥；已经登录过的那个会预先选好。Still 不会看到这次登录。

  2. 打个招呼

    直接在终端里和 Still 对话，或者在 127.0.0.1:8787 的 Still 页面上聊。

  3. 带到手机上

    说一句“连接 Telegram”，粘贴 @BotFather 给你的令牌，再在配对链接里点 Start（开始）。

    可选：用壁纸把聊天背景换成 Still 的风格（Still 形象或纯色）：在 Telegram 聊天里打开菜单，选择更换壁纸，再从相册中选它。

其余内容见快速开始指南（英文）。
