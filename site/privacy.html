Privacy draft

Publication requires confirmation of the legal operator, support contact, effective date, and hosting configuration. These values are intentionally not invented here.

Local Still data

Still is designed to retain personal state, approvals, evidence, recovery data, and managed-workspace results locally. Connected reference folders are read-only by default. Search indexes are rebuildable and separate from durable task, approval, recovery, and credential state.

Delete local data and revoke access

Local Still data stays on the owner’s device until the owner removes the relevant local application data and managed-workspace material using the operating system’s file-management tools for that installation. Do not remove connected reference folders when deleting application data: that action must not delete an owner original. For a configured provider, revoke the app’s access in that provider’s account security or permissions controls; local removal and provider revocation are separate actions.

External services and control

External AI, messaging, and provider transmissions are separate policy and approval boundaries. Local storage does not mean data is never transmitted. Google authorization and Drive access, when configured, occur between the local runtime and Google; this website is not in that path.

Website data

This static site adds no analytics, credential fields, token handling, or Drive proxy. GitHub Pages and a visitor’s network provider may process ordinary web-request metadata under their own policies.

Requests

Until an operator contact is confirmed, report repository concerns through GitHub Issues.

Still은 개인 상태, 승인, 실행 근거, 복구 자료, 관리 작업공간의 결과를 로컬에 보관하도록 설계되었습니다. 외부 AI·메신저·제공자로의 전송에는 별도의 정책과 승인 경계가 적용됩니다. 로컬에 저장한다고 해서 외부로 전혀 전송되지 않는다는 뜻은 아닙니다.

로컬 Still 자료는 소유자가 해당 설치의 운영체제 파일 관리 도구로 관련 애플리케이션 자료와 관리 작업공간 자료를 제거할 때까지 기기에 남습니다. 애플리케이션 자료를 삭제할 때 연결된 참고 폴더는 지우지 마세요. 이 작업으로 원본 파일이 삭제되어서는 안 됩니다. 연결한 제공자의 접근 권한은 해당 제공자 계정의 보안 또는 권한 설정에서 따로 철회해야 합니다. 로컬 삭제와 제공자 권한 철회는 별개의 작업입니다.
