Install and use guide

How to install Still on your computer, connect an AI and Telegram, and use it. Later sections cover registering, stopping and removing family-member instances. Run all commands in a terminal.

This page only describes install commands and screens. Do not enter any AI account or bot token on this website.

1. Install

macOS or Linux. You do not need Homebrew, Python, Docker or git.

curl -LsSf https://raw.githubusercontent.com/Jongtae/Still/main/scripts/install.sh | sh

The installer downloads the published release archive and checks its SHA-256 against the release manifest. If the values differ, nothing is installed. When it finishes, first-run setup continues in the same terminal. Later, open a new terminal and run agentos start.

macOS with Homebrew.

brew install jongtae/agentos/agentos
agentos start

Windows. Still does not run natively on Windows yet. Open the Ubuntu environment in WSL2 and run the install command above. Codex and Claude Code must also be installed and logged in inside Ubuntu. Keep the Ubuntu window open while you use Still. If no browser window opens, open http://127.0.0.1:8787 in your Windows browser.

2. First-run setup

The terminal follows your system language (Korean, Japanese, Simplified Chinese, otherwise English). Each step can be skipped with Enter. Steps you finish are kept if you stop with Ctrl-C.

  1. Access password (optional, 12+ characters). If you leave it empty, only this computer can open Still.
  2. AI connection. Choose ChatGPT (Codex), Claude (Claude Code) or an API key, or connect later in the browser.
  3. Telegram (optional). Paste the bot token from BotFather, and Still shows a pairing link.

When setup finishes, the browser opens at http://127.0.0.1:8787. You can run agentos start at any time. A finished setup is not repeated, and an interrupted one resumes at the first unfinished step.

3. Connect an AI

  • ChatGPT plan (Codex). Install the official Codex CLI and run codex login. Then confirm the Codex login in Still settings. Still does not request, read or store your Codex login. It only records that you confirmed it.
  • Claude plan (Claude Code). Install Claude Code, run claude setup-token, and paste the token once into the Claude Code token field in Still. The token is kept in this computer's private credential store and is passed only to Claude Code.
  • Direct model connection. You can use Ollama, an OpenAI-compatible Chat Completions endpoint, or an OpenAI or Anthropic API key. Choose the provider, endpoint and model name, run the connection test, and apply only a successful configuration. API keys are kept in a private local file.

Requests send conversation content to OpenAI or Anthropic. A subscription engine receives only the tools Still allows. It does not get your local files, credentials or arbitrary shell access.

4. Connect Telegram

  1. Create a new bot with BotFather in Telegram and copy its token. Use a dedicated bot that has no webhook set.
  2. In the browser, open Settings → External connections → Telegram connection settings. Paste the token and connect.
  3. Open Telegram from the link, then press Start in your own account to finish pairing.

Only the paired private account can send requests. Still uses outbound polling, so you do not need to open any public inbound port. Remote requests are processed only while the computer is on and awake.

5. Try it

Ask for what you need in the Telegram chat. For example, “My cat has been off her food lately. What should I try?” While answering, Still notes that you have a cat and tells you so, with an undo option. Later, asking “Find me a robot vacuum under $500” can take cat hair into account without you mentioning the cat again.

To check the connection without a model, send /note Review the launch on Friday, then /notes to list your notes. Use the browser to change connections and review task records.

Your data stays in ~/.local/share/agentos. Removing the program does not delete this folder. To back up, stop Still and copy the whole folder. It contains private conversations and credentials. Credentials are protected by file permissions; the application does not encrypt them separately.

7. Background service (macOS)

You can register Still to start at login so you do not need to keep a terminal open.

agentos service install    # register and start
agentos service status     # show launchd state and the health check result
agentos service restart
agentos service stop       # stop and disable persistently
agentos service start      # re-enable and start a stopped service
agentos service uninstall  # remove the registration only; data is kept
agentos service upgrade    # refresh the service definition after replacing the executable

A registered service runs with KeepAlive, so launchd restarts it when its process exits. Killing the process does not stop it. Use service stop. Automatic restart was tested with launchctl replaced by a test double; behaviour after a reboot must be confirmed on the owner's Mac.

8. Family-member instances

Each family member can have their own Still instance on this Mac, with its own memory, folders, approvals, work history and Telegram bot. Nothing is shared with your own instance.

Register

agentos family add spouse --display-name "Spouse assistant"
  • Creates and starts the instance, then uses your installed ngrok to make a temporary HTTPS setup link (about 30 minutes) and sends it to you in Telegram.
  • The family member opens the link and creates their own bot in Telegram. Your bot, folders, memory and other connections are not copied.
  • From your settings, only the AI keys or tokens that the instance needs are copied. If you change a key later, the instance keeps the old one until you set its route again.
  • To choose the port, pass --port 8797. Without it, Still uses the next free pair starting at 8797.

To register only the service, without the setup link, run the following. Names may use lowercase letters, digits and hyphens. The port must be free, and 8787 cannot be used.

agentos service install --instance spouse --port 8797

The setup page opens at http://127.0.0.1:8797/. The setup link is in that instance's private/setup-link.txt.

Check, stop, start and remove

agentos service status    --instance spouse   # check state
agentos service stop      --instance spouse   # stop and disable persistently
agentos service start     --instance spouse   # re-enable and start a stopped instance
agentos service uninstall --instance spouse   # remove the registration; data is kept

To remove an instance completely, run stop first, then uninstall. uninstall removes only the registration and keeps the data folder (~/.local/share/agentos-instances/spouse). Still has no command that deletes instance data. To delete it, stop the instance and remove that folder yourself. This cannot be undone.

9. Troubleshooting

  • The browser does not open. Before setup is finished, open the link in ~/.local/share/agentos/private/setup-link.txt on this computer. Do not send this file to anyone before setup.
  • Port conflict. Start on another port, for example agentos start --port 8788.
  • Work was interrupted. After a restart, work that was in progress is marked interrupted, and a Telegram message that was being sent is marked unknown. Still does not resend either silently. Check the web record and send a new request if needed.
  • Status summary. agentos guide shows counts and next steps only. It does not show task content or credentials.
