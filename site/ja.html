Here with you.

AI が変わっても、あなたのアシスタントは続きます。

Still は自分のコンピューターで動くオープンソースの個人エージェントです。記憶、進行中の作業、自分で設定した権限を保ちながら、使う AI を替えられます。

Still をインストール実際の利用を見る

インストールして試す ↓コマンド一つでインストールし、使っている AI を接続できます。 Engineering →記憶・判断・権限を扱う仕組みと検証資料を読めます。 開発に参加する ↓コードを読んだり、改善案を提案したりして、開発に参加できます。

AI を替えた後も、それまでの会話を続けられます。

コーヒー豆を選ぶ途中で Codex から Claude Code へ。次の依頼では、前の提案を説明し直さずに会話が続きます。

必要に応じて AI やツールを替えられます

  • Codex
  • Claude Code
  • API で接続する AI
  • Ollama
  • 接続したツール

AI を替えても記憶や作業の記録は残ります

  • あなたについて知ったこと
  • やりかけの仕事
  • あなたが任せた権限
  • 実際に実行された記録

Still を始めましょう

Mac、Linux、Windows（WSL2）で利用できます。ChatGPT・Claude のサブスクリプション、API キー、Ollama のいずれかを接続して始められます。

curl -LsSf https://raw.githubusercontent.com/Jongtae/Still/ebf97d4150be3eb867649a31e79287f05db02886/scripts/install.sh | sh

インストールスクリプトはアドレスでバージョンが固定されています。実行する前にスクリプトの内容を確認してください。Apple シリコンの Mac で Homebrew を使うなら brew tap jongtae/still https://github.com/Jongtae/Still、brew install jongtae/still/agentos のあと agentos start で起動します。Windows では PowerShell で wsl --install を実行して再起動し、Ubuntu を開いてそこにコマンドを貼り付けてください。

  1. 使いたい AI を接続してください

    インストール後、ターミナルで AI を接続します。ChatGPT は Codex、Claude は Claude Code で利用でき、API キーや Ollama も選べます。ログイン済みの AI はあらかじめ選択されます。

  2. Still と会話を始めてください

    ターミナルで話しかけるか、ブラウザーで 127.0.0.1:8787 を開いて会話できます。利用中はターミナルの agentos start を実行したままにしてください。

  3. Telegram でスマートフォンからも話せます

    「Telegram をつないで」と言い、@BotFather から受け取ったトークンを非表示の入力欄に貼り付けて、ペアリングリンクで「開始」を押します。

    お好みで、トークの背景も Still の雰囲気に。壁紙（Still の姿または無地）を使うなら、Telegram のトーク画面でメニューを開き、壁紙を変更を選んで写真から選んでください。

そのほかはクイックスタートガイド（英語）にあります。

以前の会話を踏まえて、次の作業を始められます。

これまでの会話や保存した記憶を次の依頼に活かし、自分で接続したツールを使って作業します。

会話で伝えた好みを、次の依頼に活かします。

以前伝えた好みや状況を覚えておき、関連する依頼で参考にします。記憶の根拠を確認し、保存した内容を取り消すこともできます。

会話の例

月曜日

最近、猫がごはんをあまり食べない。どうしたらいい？

まず試してみたいことがいくつかあります…猫を飼っていることを覚えておきますね。

木曜日

5万円以下のロボット掃除機を選んで。

5万円以下で3台あります。猫の毛にいちばん強いものを最初に置きました。

実際の画面を開く

使い慣れたアプリで話し、普段使うツールを接続できます。

作業に接続できるツール

フォルダーは、特に言わない限り読み取り専用です。Gmail の整理は別の権限で、Still がメールを送ることはありません。

作業中も質問したり、依頼を変更したりできます。

時間のかかる作業を始める前に、計画と担当する AI を伝えます。作業中も別の質問をしたり、進め方を変更したりできます。

会話の例

母の誕生日プレゼントを5千円以下で探して。

Codex毎日使えそうなものを探して、レビューと配達日を確かめてから、3つお見せします。

「ありがとう」って英語でなんて言う？

Thank you です。プレゼント探しはまだ続いています。

  • 設定した権限の範囲で作業します。 フォルダー、アカウント、ツールに設定したアクセス範囲と操作権限に従います。
  • 支払いのたびに承認が必要です。 商品をカートに入れた後も、支払いには別途あなたの承認が必要です。
  • パスワードやトークンを保護します。 AI モデルに渡す内容、ログ、実行記録には含めません。

Engineering — この設計を選ぶ理由

記憶や作業を保つ仕組み、AI の判断、利用者の権限を扱う設計を説明します。実装済みの機能、検証した範囲、今後の設計を区別し、元の文書やコードを案内します。
