インストールと使い方

この Mac に Still をインストールし、AI と Telegram を接続して使うまでの手順です。後半では、家族用インスタンスの登録・停止・削除を説明します。コマンドはすべてターミナルで実行します。

このページはインストールコマンドと画面の流れだけを説明します。このウェブサイトに AI アカウントやボットトークンを入力しないでください。

1. インストール

macOS または Linux. Homebrew、Python、Docker、git は不要です。

curl -LsSf https://raw.githubusercontent.com/Jongtae/Still/main/scripts/install.sh | sh

インストーラーは公開リリースのアーカイブを取得し、SHA-256 をリリースマニフェストと照合します。値が一致しなければ何もインストールしません。完了すると、同じターミナルで初回設定が続きます。次回からは新しいターミナルで agentos start を実行します。

macOS（Homebrew）.

brew tap jongtae/still https://github.com/Jongtae/Still
brew install jongtae/still/agentos
agentos start

Windows. Still はまだ Windows でネイティブには動作しません。WSL2 の Ubuntu を開き、上のインストールコマンドを実行します。Codex や Claude Code も Ubuntu 内にインストールしてログインする必要があります。Still を使う間は Ubuntu のウィンドウを開いたままにしてください。ブラウザーが開かない場合は、Windows のブラウザーで http://127.0.0.1:8787 を開きます。

2. 初回設定

ターミナルはシステムの言語（韓国語、日本語、中国語（簡体字）、それ以外は英語）に従います。各ステップは Enter で飛ばせます。完了したステップは、Ctrl-C で中断しても保存されます。

  1. アクセスパスワード（任意、12文字以上）。空欄のままにすると、このコンピューターからだけ Still を開けます。
  2. AI の接続。ChatGPT（Codex）、Claude（Claude Code）、API キーから選ぶか、後でブラウザーから接続します。
  3. Telegram（任意）。BotFather で受け取ったボットトークンを貼り付けると、Still がペアリングリンクを表示します。

設定が終わると、ブラウザーで http://127.0.0.1:8787 が開きます。agentos start はいつでも実行できます。完了した設定は繰り返されず、途中で止めた場合は未完了の最初のステップから再開します。

3. AI を接続する

  • ChatGPT プラン（Codex）。公式の Codex CLI をインストールし、codex login を実行します。その後、Still の設定で Codex のログイン完了を確認する項目を選びます。Still は Codex のログイン情報を要求・読み取り・保存しません。完了したという確認だけを記録します。
  • Claude プラン（Claude Code）。Claude Code をインストールし、claude setup-token を実行します。表示されたトークンを、Still の Claude Code トークン欄に一度貼り付けます。トークンはこのコンピューターの非公開の認証情報ストアに保管され、Claude Code にだけ渡されます。
  • 直接のモデル接続。Ollama、OpenAI 互換の Chat Completions エンドポイント、OpenAI または Anthropic の API キーを使えます。プロバイダー、エンドポイント、モデル名を選び、接続テストに成功した設定だけを適用します。API キーは非公開のローカルファイルに保管されます。

リクエストの会話内容は OpenAI または Anthropic に送信されます。サブスクリプションのエンジンには、Still が許可したツールだけが渡されます。ローカルファイル、認証情報、任意のシェルには接続されません。

4. Telegram を接続する

  1. Telegram の BotFather で新しいボットを作成し、トークンをコピーします。Webhook が設定されていない専用のボットを使ってください。
  2. ブラウザーで Still の設定を開き、外部接続の Telegram 接続設定を選びます。トークンを貼り付けて接続します。
  3. Telegram を開く操作を行い、ご自身のアカウントでボットの Start を押すとペアリングが完了します。

ペアリングされた非公開アカウントだけがリクエストを送れます。Still は送信のポーリングで通信するため、公開の受信ポートを開く必要はありません。リモートからのリクエストは、コンピューターが電源オンで起きている間だけ処理されます。

5. 試してみる

Telegram のチャットで必要なことを頼みます。例えば「うちの猫が最近ごはんを食べないの。何を試したらいい？」と尋ねると、Still は回答しながら猫を飼っていることを覚え、その旨を伝えます（取り消しも可能です）。後で「500ドル以下のロボット掃除機を探して」と頼めば、猫の話をしなくても毛の多さを考慮した回答が得られます。

モデルを使わずに接続を確認するには、/note 金曜日のリリースを確認 を送り、/notes でメモ一覧を表示します。接続の変更や作業記録の確認はブラウザーで行います。

6. 再起動・更新・削除

目的コマンド
再起動agentos start
更新（Homebrew）実行中であれば Ctrl-C で止めてから、brew update、brew upgrade jongtae/still/agentos、agentos start を実行
更新（インストールスクリプト）インストールコマンドをもう一度実行
プログラムの削除（uv でインストールした場合）uv tool uninstall personal-agentos
現在の状態の確認agentos guide（作業内容や認証情報は表示されません）

データは ~/.local/share/agentos に残ります。プログラムを削除してもこのフォルダーは消えません。バックアップする場合は、Still を止めてからフォルダー全体をコピーしてください。フォルダーには非公開の会話と認証情報が含まれます。認証情報はファイルの権限で保護されており、アプリケーションが別途暗号化するものではありません。

7. バックグラウンドサービス（macOS）

ログイン時に Still が自動的に起動するよう登録できます。ターミナルを開いたままにしておく必要はありません。

agentos service install    # 登録して起動
agentos service status     # launchd の状態と健全性チェックの結果を表示
agentos service restart
agentos service stop       # 停止し、永続的に無効化
agentos service start      # 停止中のサービスを再度有効にして起動
agentos service uninstall  # 登録のみ削除（データは残ります）
agentos service upgrade    # 実行ファイルを入れ替えた後、サービス定義を更新

登録されたサービスは KeepAlive で動作するため、プロセスが終了すると launchd が再起動します。プロセスを kill しても止まりません。service stop を使ってください。自動再起動は launchctl を試験用に置き換えた環境でのみ確認しています。再起動後の動作はオーナーご自身の Mac で確認が必要です。

8. 家族用インスタンス

家族それぞれに、この Mac 上で専用の Still インスタンスを用意できます。インスタンスは独自のメモリ、フォルダー、承認、作業履歴、Telegram ボットを持ちます。ご自身のインスタンスとは何も共有されません。

登録

agentos family add spouse --display-name "配偶者のアシスタント"
  • インスタンスを作成して起動し、インストール済みの ngrok で一時的な HTTPS 設定リンク（約30分有効）を作成して、Telegram で送信します。
  • 家族の方はリンクを開き、ご自身の Telegram でボットを作成します。ご自身のボット、フォルダー、メモリ、他の接続はコピーされません。
  • ご自身の設定から、インスタンスに必要な AI のキーやトークンだけをコピーします。後でキーを変更しても、インスタンスは再設定するまで古いキーを使い続けます。
  • ポートを指定するには --port 8797 のように渡します。省略すると、8797 から空いているペアを順に使います。

設定リンクを使わずにサービスだけを登録する場合は、次のコマンドを使います。名前には小文字、数字、ハイフンを使えます。ポートは空いている必要があり、8787 は使えません。

agentos service install --instance spouse --port 8797

設定画面は http://127.0.0.1:8797/ で開きます。設定リンクは、そのインスタンスの private/setup-link.txt にあります。

確認・停止・開始・削除

agentos service status    --instance spouse   # 状態を確認
agentos service stop      --instance spouse   # 停止し、永続的に無効化
agentos service start     --instance spouse   # 停止中のインスタンスを再度有効にして起動
agentos service uninstall --instance spouse   # 登録のみ削除（データは残ります）

インスタンスを完全に削除するには、先に stop、次に uninstall を実行します。uninstall は登録だけを削除し、データフォルダー（~/.local/share/agentos-instances/spouse）は残します。Still にはインスタンスのデータを削除するコマンドはありません。データも削除する場合は、インスタンスを停止してからそのフォルダーを手動で削除してください。この操作は元に戻せません。

9. トラブルシューティング

  • ブラウザーが開かない。設定が終わるまでは、このコンピューター上の ~/.local/share/agentos/private/setup-link.txt にあるリンクを開いてください。設定が終わるまでこのファイルを他人に送らないでください。
  • ポートが競合する。agentos start --port 8788 のように別のポートで起動します。
  • 作業が途中で中断された。再起動後、実行中だった作業は中断として、送信中だった Telegram メッセージは不明として表示されます。Still はどちらも黙って再送しません。ウェブの記録を確認し、必要であれば新しくリクエストしてください。
  • 状態の要約。agentos guide は件数と次の手順だけを表示し、作業内容や認証情報は表示しません。
