AI는 바뀌어도, 나의 비서는 이어집니다.

Still은 내 컴퓨터에서 실행하는 오픈소스 개인 에이전트입니다. 나에 대한 기억과 진행 중인 일, 내가 허용한 작업 범위를 유지하면서 AI를 바꿔 쓸 수 있습니다.

지금 Still을 시작하세요

Mac, Linux 또는 Windows(WSL2) 컴퓨터에서 사용할 수 있습니다. ChatGPT·Claude 구독, API 키, Ollama 중 하나를 연결해 시작하세요.

curl -LsSf https://raw.githubusercontent.com/Jongtae/Still/ebf97d4150be3eb867649a31e79287f05db02886/scripts/install.sh | sh

설치 스크립트는 주소에 특정 버전으로 고정되어 있습니다. 실행하기 전에 스크립트 내용을 확인하세요. Apple Silicon Mac에서 Homebrew를 쓴다면 brew tap jongtae/still https://github.com/Jongtae/Still, brew install jongtae/still/agentos로 설치한 뒤 agentos start로 시작합니다. Windows에서는 PowerShell에서 wsl --install을 실행하고 다시 시작한 뒤, Ubuntu를 열고 위 명령을 붙여 넣으세요.

  1. 사용할 AI를 선택하세요

    설치 후 터미널에서 AI를 연결합니다. ChatGPT 구독은 Codex로, Claude 구독은 Claude Code로 연결하며, API 키나 Ollama도 선택할 수 있습니다. 이미 로그인한 AI는 미리 선택됩니다.

  2. Still과 대화를 시작하세요

    터미널에서 바로 말을 걸거나, 브라우저로 127.0.0.1:8787을 열어 대화하세요. 사용하는 동안에는 터미널의 agentos start를 계속 실행해 두세요.

  3. Telegram으로 휴대폰에서도 대화하세요

    “Telegram 연결해 줘”라고 말하고, @BotFather가 준 토큰을 숨김 입력 칸에 붙여 넣은 뒤 페어링 링크에서 시작을 누르세요.

    원하면 대화방도 Still 분위기로 꾸며 보세요. 배경화면(Still 모습 또는 단색)을 내려받은 뒤, Telegram 대화방 메뉴 → 배경화면 변경에서 사진으로 고르면 됩니다.

자세한 설치·연결 방법은 빠른 시작 안내에서 확인하세요.

이전 대화를 바탕으로 다음 일을 시작합니다.

앞서 나눈 대화와 저장한 기억을 다음 요청에 활용하고, 내가 연결한 도구로 일을 진행합니다.

대화에서 알게 된 취향을 다음 요청에 활용합니다.

이전에 알려 준 취향과 상황을 기억해 두고, 관련된 요청을 할 때 참고합니다. 기억의 근거를 확인하고, 저장한 내용을 취소할 수 있습니다.

작업 중에도 질문하거나 요청을 수정할 수 있습니다.

시간이 걸리는 일을 시작할 때는 작업 계획과 담당 AI를 알려 줍니다. 작업이 진행되는 동안 다른 질문을 하거나, 원하는 방향을 바꿔 말할 수 있습니다.

사용 장면 예시

엄마 생일 선물, 5만 원 이하로 찾아 줘.

Codex매일 쓰실 만한 걸로 찾아볼게요. 후기와 배송일을 확인한 뒤 세 가지를 보여 드릴게요.

일본어로 고맙다는 말 어떻게 해?

“아리가토 고자이마스”예요. 선물은 계속 찾고 있어요.

  • 내가 허용한 범위에서 일합니다. 폴더·계정·도구에 설정한 접근 범위와 작업 권한을 따릅니다.
  • 결제할 때마다 내 승인을 받습니다. 상품을 장바구니에 담았더라도, 결제를 진행하려면 별도로 승인해야 합니다.
  • 비밀번호와 토큰을 보호합니다. 비밀번호와 토큰은 AI 모델에 전달하는 내용이나 로그, 실행 기록에 포함하지 않습니다.

Engineering — 왜 이렇게 설계했을까요?

Still이 기억과 작업을 유지하는 구조, AI의 판단 방식, 사용자 권한을 다루는 설계를 설명합니다. 구현된 기능과 검증한 범위, 앞으로의 설계 방향을 구분하고 관련 문서와 코드를 연결합니다.
