# 3. 기억과 학습

[주제별 목차](README.md) · 개념 해설; 저장·승인·삭제의 정본은 영문 계약

## 문제: 많이 저장하는 것과 잘 기억하는 것은 다르다

대화 전체를 보관해도 필요한 사실을 찾지 못할 수 있다. 반대로 짧은 프로필은 중요한 맥락을 잘라내고, 요청 한 번의 조건을 영구적인 성향으로 만들 수 있다. Still의 기억 문제는 저장량 하나가 아니라 **무엇을 사실로 남기고, 언제 유효하며, 지금 요청에 무엇을 전달하는가**라는 연결된 문제다.

[Owner model 연구](../research/owner-model-and-decision-journal-2026-09-28.ko.md)와 [기억·dream 실험](../research/memory-and-dream-experiments-2026-10-22-to-11-05.ko.md)은 이 문제를 서로 다른 시기의 제안과 관찰로 다룬다. 새 본문은 그 자료를 같은 수준의 검증 결과로 합치지 않는다.

## 서로 다른 기억을 한 통에 넣지 않는다

| 대상 | 목적 | 주의할 경계 |
| --- | --- | --- |
| 대화 원문 | 무엇을 실제로 말했는지 회수 | 모델의 답이나 개발용 호출을 소유자의 말로 승격하지 않음 |
| 현재 맥락(Context) | 지금 요청의 상황·대상·제약을 이해 | 일시적 조건이 곧 영구적 선호는 아님 |
| 지속적 기억(Memory) | 다시 쓸 사실·선호를 출처와 함께 유지 | 추론, 유효 시점, 교체·무효 상태를 구분 |
| 작업 메모(working notes) | 이 사람을 위해 일하는 방법을 개선 | 소유자에 대한 사실과 수행 방법을 혼합하지 않음 |
| 하루 기록 | 과거 상황을 다시 찾는 단서 | 요약을 독립적인 사실의 출처로 재활용하지 않음 |

이 구분은 새 저장소 다섯 개를 요구하지 않는다. [Current Context](../current-context-contract.en.md)와 [Secretary Agency](../secretary-agency-contract.en.md)가 정하는 서로 다른 수명·출처·용도를 설명한다.

## 기억을 고친다는 것은 현재성을 바꾸는 일이다

현재 계약은 새 사실을 덧붙이고 대체된 사실을 무효 처리하는 구조를 설명한다. 이전 기록을 무조건 덮어쓰지 않아야 무엇을 왜 바꿨는지와 되돌릴 대상을 알 수 있다. '잊어줘'에 따른 무효화와 실제 삭제도 다르다. 이 구분은 모든 데이터를 영구 보관하자는 원칙이 아니며, 원격 사본까지 삭제되었다는 보장도 아니다.

예를 들어 '이번 달만 비용을 줄이자'는 상황별 제약이다. 이를 '항상 가장 싼 것을 선호한다'로 바꾸면 저장에 성공했어도 기억은 잘못된 것이다. 이 예시는 설계상 실패를 설명하며 실제 소유자의 데이터가 아니다.

소유자 자신의 AI가 기억을 저장하는 경로와 제3자·위임 작성자가 MemoryCandidate를 제안하는 경로는 다르다. 소유자 AI의 전경 저장은 알림과 정확한 되돌리기를 갖지만, 제3자에게 같은 자동 저장 권한을 주지는 않는다. 상세 조건은 [Secretary Agency](../secretary-agency-contract.en.md)의 현재 규칙을 따른다.

## 대화 중 저장과 밤사이 정리를 구분한다

전경 저장은 당장의 이해를 남긴다. dream은 여러 요청을 돌아보며 누락된 사실을 찾고 정리하고 수행 방법을 돌아보는 과정이다. 현재 계약은 출처가 되는 소유자 발언을 제한하고, 정리로 끝낼 기억의 근거를 요구하며, 배경 통합을 매번 알림으로 보내지 않도록 구분한다.

따라서 '모든 저장은 항상 같은 알림을 보낸다'도, '아무 말 없이 기억해도 된다'도 전체 규칙이 아니다. [기억을 알리는 방식 연구](../research/memory-telling-2026-10-30.ko.md)는 조용한 통합, 관련된 다음 대화에서의 확인, 실제 답변에서 기억을 사용하는 경험을 함께 다룬다. 수행 메모의 개정 알림은 별도의 경로를 유지한다.

실패에서 배운다는 말도 제한되어야 한다. 관찰된 실패와 소유자의 정정에서 얻은 좁은 교훈을, 모든 상황에 적용할 사용자 성향으로 확대해서는 안 된다. 현재 계약의 #496 보완은 이전 실패 자료를 수행 메모의 근거로 제한하고, 사실·무효화·하루 기록의 근거와 분리한다.

## 실험으로 알게 된 것과 아직 모르는 것

[공개 실험 기록](../research/memory-and-dream-experiments-2026-10-22-to-11-05.ko.md)은 단순 절단 해제, 기억 구조 변경, 사실 수집과 정리의 분리, 출처 표시가 서로 다른 문제를 해결한다고 보여 주는 탐색 자료다. 더 많은 필요 사실을 전달하는 것과 오래된 정보를 현재처럼 노출하지 않는 것은 별도로 확인해야 한다.

오프라인 재생은 모델 판정이며 정답 세트의 소유자 검증과 반복 잡음에 한계가 있다. 원문의 소규모 실제 사용 점검도 별개의 관찰이다. 조용히 저장된 내용을 사용자가 되돌리지 않았다고 정확했다고 볼 수 없다. 이 결과를 제품 전체의 기억 정확도나 일반적인 성능 향상률로 표현하지 않는다.

## 남아 있는 질문

짧은 상시 맥락과 요청 시점의 원문 회수를 어떻게 조합할지, 사실의 낡음을 어떻게 감지할지, 잘못된 학습을 적은 부담으로 고칠 수 있을지가 남아 있다. 저장·회수·정정·사용·설명을 하나의 여정으로 검증해야 한다.
