# Product direction

This page is a direction entry, not an implementation queue or a capability inventory. [Product status](product-status.en.md) records evidence and limits; root [delivery-plan.yaml](../delivery-plan.yaml) owns current goal selection; GitHub owns issue/PR/check status.

## Durable direction

Still explores a personal agent that keeps the owner's memory, open work, permissions and results while the AI and execution tools can change. Useful continuity must survive questions, corrections, failures and recovery; a natural voice alone is insufficient. The motivation is in [VISION](VISION.md), and the connected argument is in [Concepts](concepts/README.md).

The design separates semantic judgment from exact authority and evidence boundaries. Role and skill knowledge can broaden how work is understood without adding scenario-specific branches or granting new authority. The applicable [current contracts](README.md#current-contracts-by-responsibility) remain authoritative.

Agent packages and distribution are an extension direction, not a reason to postpone useful default behavior or a claim that an arbitrary-code marketplace is available. See [ecosystem hypotheses](concepts/ecosystem-and-business.ko.md) and the [Platform Foundation](agent-distribution-platform-foundation.en.md).

These are continuing questions and principles, not newly selected priorities, dates or commitments. This document makes no release-wide or live-service validation claim.
