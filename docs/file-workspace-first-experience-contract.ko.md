# FILE-WS-A-01 — 파일·폴더 개인 작업공간 결정

> **과거 참고용 한국어 번역본.** 내부 개발 기준은 [영어 원본](file-workspace-first-experience-contract.en.md)을 따른다.

## 상태와 사용자 결과

이 문서는 소유자가 승인한 #314 프로그램 안의 FILE-WS-A-01 이슈 #318 설계 계약이다. 제품 기준과 계획만 바꾸며 파일 수집 기능을 구현하지 않는다.

Still은 사용자 파일·폴더를 자료 기반으로, 대화·작업을 경험으로 삼는 로컬 우선 개인 에이전트다. 이후 첫 흐름은 사용자가 자료를 맡기면 Still이 원본을 보존하고, 회의록 또는 요약을 일반 TXT/MD 파일로 만들며, 재시작 뒤 다른 대화에서 그 결과를 찾아 다시 활용하는 것이다.

## 제품 결정

파일과 폴더가 기본 자료 시스템이다. Still은 이미 연결한 자료를 매번 다시 찾게 하는 파일 선택기도, 자체 동기화 서비스도 아니다. 기존 사용자가 선택한 동기화 앱이 파일을 동기화할 수 있으며 Still은 동기화 엔진이나 중앙 인증 서비스를 추가하지 않는다.

Google Drive 등 서비스별 connector는 선택한 자료를 가져오거나 서비스 고유 작업을 하는 선택 capability다. 필수 기반이나 핵심 보관 경로가 아니다. #308, #310, #311, #312의 Drive 작업은 보존된 선택 작업으로 남는다. #313은 독립된 제품 안내·정책 사이트 작업이며 로컬 파일 경험의 선행조건이 아니다.

## 저장과 출처 경계

| 분류 | 위치와 규칙 |
| --- | --- |
| 원본 | 맡긴 원본 파일을 보존한다. Markdown·요약·전사로 대체하지 않는다. |
| 파생 자료 | 추출 텍스트·전사·요약은 따로 저장하고 원본과의 출처 관계를 기록한다. |
| 작업 산출물 | 초안과 확정 기록을 구분한다. 확정 회의록 또는 요약은 관리 작업공간의 일반 TXT/MD 파일이다. |
| 재생성 가능한 인덱스 | 검색·인덱스 산출물은 사용자 파일과 분리하고 다시 만들 수 있게 한다. |
| 영속 내부 상태 | 작업 큐·승인·근거·복구 상태·인증정보는 인덱스와 분리한다. 버려도 되는 cache가 아니다. |

후속 구현은 경로만으로 불변 identity를 가정하지 않고 안정된 불투명 source/result reference와 출처를 기록한다. 기존 사용자 데이터와의 호환성을 보존하며 파괴적 migration을 하지 않는다.

## 접근과 행동 경계

- 연결한 참고 폴더는 기본 읽기 전용이다. 승인된 범위는 매번 파일 선택을 요구하지 않고 검색·읽기할 수 있다.
- Still 관리 작업공간은 소유자가 허용한 작업공간 범위 안에서만 새 자료와 결과물을 만들 수 있다.
- 폴더 연결은 홈 디렉터리 접근, 임의 셸 실행, 원본 덮어쓰기·삭제·대량 이동·외부 전송 권한이 아니다.
- 원본 덮어쓰기·삭제, 대량 이동, 모든 외부 AI·메신저·에이전트·수신자 전송은 별도 명시 정책/승인 경계다. 로컬 저장은 어떤 정보도 전송되지 않는다는 주장이 아니다.

## 첫 구현 계약

FILE-WS-B-01 (#315)은 이 영어 원본 계약이 병합되고 goal-ready issue가 현재 상태일 때만 활성화할 수 있다. 독립 데모가 아니라 기존 대화 경로와 통합해야 한다. TXT/MD가 최초 검증 형식이며 이미 지원하는 형식도 검증된 경계에서만 재사용한다.

최소 갱신 정책은 사용자 수정·이름 변경·삭제를 감지해 오래된 검색/출처 상태를 안전하게 처리해야 한다. 가능하면 갱신·재색인하고, 그렇지 않으면 오래된 결과를 빼고 결정적인 복구를 제공한다. 승인 범위 밖을 읽거나 삭제된 원본을 다시 만들면 안 된다.

## 필요한 자동 증거

FILE-WS-B-01은 실제 개인 자료가 아닌 전용 테스트 폴더와 샘플 자료를 사용해 저장 → 재시작 → 검색/재활용 통합 흐름을 증명해야 한다. 폴더 범위/경로 이탈 거절, 원본 보존, 중복 저장, 승인 없는 외부 전송 거절도 다룬다. 모의 모델, 실제 로컬 파일, 실제 외부 엔진/Telegram 관찰은 서로 다른 증거 유형이다.

## 비목표와 후속 단계

이 계약은 OCR, 음성 전사, 영상 분석, 큰 자료함의 고급 검색, 클라우드 전용 문서 가져오기, 자료 묶음 위임·결과 회수, 동기화 엔진, 새 인증정보, 실제 외부 운영을 구현하지 않는다. 이들은 첫 흐름의 완료 조건이 아니라 별도 후속 작업이다.

FILE-WS-C-01 (#316)은 FILE-WS-B-01 뒤에 독립 검토, 요구사항-증거 audit, 구현 PR closeout 증거를 만든다.
